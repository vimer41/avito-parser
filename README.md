# ⚡️ AVITO RADAR

**AVITO RADAR** — профессиональный программный комплекс и Telegram-бот для непрерывного высокоскоростного перехвата новых объявлений и аналитики снижения цен на классифайде «Авито» в режиме реального времени.

Комплекс спроектирован для профессиональных байеров, специалистов по перепродаже (resale), арбитража сделок и мониторинга коммерческих закупок. Бот доставляет новые лоты за секунды до того, как они попадут в поле зрения конкурентов, снабжая каждое объявление HD-фотографиями, аналитическими бейджами и инструментами быстрой реакции.

## 🛠 Ключевые инженерные решения и архитектура

Система оптимизирована для работы в условиях ограниченных ресурсов (от 512 МБ RAM на недорогих VPS) и гарантирует надежность 24/7.

```
                    ┌────────────────────────────────────────────────────────┐
                    │                      АВИТО (AVITO)                     │
                    └───────────────────────────┬────────────────────────────┘
                                                │
                                    HTTP/2, TLS Chameleon
                                                │
                                                ▼
                    ┌────────────────────────────────────────────────────────┐
                    │            CORE PARSER ENGINE (parser.py)              │
                    │  • Извлечение SSR JSON State (__initialData__) < 5 ms  │
                    │  • Обогащение через Mobile API (/api/1/card/items)     │
                    │  • Anti-Bot Suite (Qrator XTEA, PoW, GeeTest v4 ONNX)  │
                    └───────────────────────────┬────────────────────────────┘
                                                │
                                                ▼
                    ┌────────────────────────────────────────────────────────┐
                    │          SCHEDULER & PIPELINE (scheduler.py)           │

                    │  • Семантическая фильтрация (стоп-слова, ЧС)           │
                    │  • Детекция снижения цен (Price Drop Alert)            │
                    │  • Загрузка фото через CDN c80.img.avito.st (aiohttp)  │

                    │  • Telegram Bot (aiogram 3.x, SPA in-place navigation) │
                    └────────────────────────────────────────────────────────┘
```

### 1. Парсинг данных через SSR JSON State (< 5 мс)
Вместо медленного разбора тяжелого DOM-дерева через BeautifulSoup/lxml ядро парсера напрямую извлекает серверное состояние (`__initialData__` / SSR JSON). Задержка парсинга составляет менее 5 мс на страницу, процессор свободен от лишней нагрузки.

### 2. Загрузка HD-фотографий через Anycast CDN (`aiohttp`)
- Фотографии лотов скачиваются через выделенную сессию `aiohttp` с пулом соединений прямо из глобального CDN `c80.img.avito.st`.
- Парсер не блокируется тяжелыми вызовами curl_cffi в потоках.
- Фотографии конвертируются и отправляются со 100% надежностью без пустых заглушек.

### 3. Защита от спама и гонки состояний (Anti-Race & Cache Stampede)
- **Item Lock Pool**: Если одно и то же выгодное объявление попадает под радары сразу нескольких пользователей, асинхронные замки `get_item_lock` гарантируют, что фото скачивается ровно **1 раз**.
- **RAM LRU/TTL Cache**: Полученный от Telegram `file_id` кэшируется в оперативной памяти. Всем остальным пользователям картинка улетает за сотые доли секунды по `file_id` без повторного расхода интернет-трафика сервера.
- **Outbox Queue Pattern**: Парсинг каталога и отправка в Telegram развязаны через очередь `asyncio.Queue`, гарантируя стабильную работу даже при временных сетевых просадках.

### 4. 📉 Отслеживание снижения цен продавцов (Price Drop Alert) 💎
Эксклюзивная функция тарифа **PRO**:
- Бот запоминает первоначальную цену каждого лота в таблице `seen_items`.
- Если продавец сбрасывает цену на заданный процент (-5%, -10%, -15%, -20%, -30%, -50% или **любой свой от 1% до 99%**), бот мгновенно отправляет повторный пуш с расчетом чистой выгоды в рублях:
  `📉 СНИЖЕНИЕ ЦЕНЫ · AVITO RADAR [-15%]`  
  `🏷 85 000 ₽ (было 100 000 ₽ · выгода 15 000 ₽)`

### 5. 🔍 Выбор области поиска (Только в заголовке / Заголовок + Описание)
Каждый радар можно гибко переключать в 1 клик:
- `Только в названии` — максимальная точность, отсекаются случайные упоминания в тексте описания.
- `В названии и описании` — максимальный охват для редких позиций и запчастей.

### 6. 💬 Встроенная служба поддержки (Helpdesk / Ticket System)
Пользователи могут отправить вопрос, скриншот, квитанцию об оплате, голосовое или документ прямо в чат с ботом по кнопке **«💬 Поддержка»**. Администраторы получают карточку обращения с кнопкой `[ ✍️ Ответить ]` и ведут переписку с пользователем прямо через интерфейс бота.

### 7. 📱 Эргономика интерфейса: SPA Single-Page Navigation
Все переходы по разделам меню, профилю, тарифам и настройкам радаров выполняются на месте (`edit_text`) без спама сотнями сообщений в истории диалога. В каждом меню предусмотрены кнопки `[ 🔙 Назад ]` и `[ 🏠 В главное меню ]`.

## 🛡 Комплекс преодоления сетевых защит (Anti-Bot Suite)

В систему встроен автономный модуль нейтрализации систем защиты:

| Защита | Механизм нейтрализации | Описание |
| :--- | :--- | :--- |
| **TLS / HTTP/2 Fingerprint** | Эмуляция `curl_cffi` | Имитация профиля актуального браузера (совпадающий шифросьют TLS, аутентичные JA3/JA4, HTTP/2 селекторы). |
| **Qrator Security Platform** | XTEA-кодек и генерация фингерпринтов | 32-раундовый шифр XTEA для полей `f` и `s`, динамический синтез параметров WebGL/Canvas, протокольный обмен `/web/2/ft` и `/web/1/u`. |
| **Proof-of-Work (PoW)** | Асинхронный криптоподбор | Перехват JWT-челленджей из ответов 429/439 и параллельный расчет контрольного значения SHA-256 `nonce`. |
| **GeeTest v4** | Локальный ONNX-инференс | Распознавание координат слайдера и семантических иконок локальной нейросетью без платных внешних сервисов. |
| **Сессионный пул** | Валидация куки | Хранение и автопродление сессионных куки в `avito_cookies.json`. |

## 🚀 CI/CD Pipeline и автоматический деплой

Проект оснащен полноценным конвейером непрерывной интеграции и доставки на базе **GitHub Actions** (`.github/workflows/deploy.yml`):

1. **Автоматическое тестирование (Test Suite)**:
   При каждом `git push` в ветки `feature/json-api` или `main` автоматически прогоняются 7 изолированных асинхронных тестов (`tests/test_system.py`):
   - Проверка выдачи 24h триала новым юзерам;
   - Проверка лимитов радаров (триал: 2, стандарт: 5, про: 15, админ: max);
   - Валидация форматирования дат в часовом поясе МСК;
   - Проверка полного каскадного удаления пользователей;
   - Проверка TTL-кэша и замков против гонки состояний;
   - Проверка компиляции всего исходного кода (`py_compile`).
2. **Автоматический деплой на VPS (Deploy Job)**:
   При успешном прохождении тестов GitHub Actions по SSH подключается к вашему серверу, обновляет репозиторий, устанавливает зависимости и бесшовно перезапускает сервис `avito-bot.service` через systemd.

## ⚙️ Установка и запуск

### 1. Быстрый запуск на Linux VPS (systemd)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vimer41/avito-tracker2.git /opt/avito_parser_bot
   cd /opt/avito_parser_bot
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
3. Создайте файл `.env`:
   ```env
   BOT_TOKEN=1234567890:AAExampleTokenHere
   ADMIN_ID=986832959
   ADMIN_IDS=986832959,455386428
   CHECK_INTERVAL=60
   MAX_SEARCHES_PER_USER=10
   MAX_CONCURRENT_WORKERS=3
   ```
4. Установите и запустите службу `avito-bot.service`:
   ```bash
   sudo cp avito-bot.service /etc/systemd/system/avito-bot.service
   sudo systemctl daemon-reload
   sudo systemctl enable --now avito-bot
   sudo systemctl status avito-bot
   ```

### 2. Настройка автоматического деплоя (CI/CD)

В репозитории GitHub перейдите в **Settings -> Secrets and variables -> Actions** и добавьте:
- `VPS_HOST` — IP-адрес вашего сервера;
- `VPS_USERNAME` — логин (обычно `root`);
- `VPS_PASSWORD` — пароль к серверу (или `VPS_SSH_KEY`).

При каждом пуше в ветку `feature/json-api` бот будет автоматически тестироваться и обновляться на сервере!

## 👑 Команды администратора

- `/admin` или `👑 Админ-панель` — Сводная статистика, управление доступом, список пользователей с их тарифами и остатком времени.
- `/db` или `/backup` — Мгновенное скачивание резервной копии базы данных SQLite (WAL-безопасная копия через SQLite Online Backup API).
- `/delete_user @username` или `/purge_user <ID>` — Полное и безвозвратное стирание пользователя из базы данных и журналов логов.
- Выгрузка системных логов в Telegram в виде ZIP-архива в 1 клик прямо из панели управления.
