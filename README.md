# 🤖 Avito Parser Telegram Bot (24/7 Мониторинг новых объявлений)

Современный и надежный Telegram-бот для мгновенного отслеживания новых объявлений на **Авито** по любым вашим поисковым ссылкам и фильтрам.

Как только продавец публикует товар на Авито — бот моментально присылает карточку с фотографией, ценой, городом, доставкой, описанием и кнопкой быстрого перехода.

---

## 🌟 Основные возможности

* ⚡️ **Мгновенные уведомления**: Мониторинг в реальном времени с настраиваемым интервалом (по умолчанию 60 сек).
* 🛡 **Автообход защиты Авито**: Встроенное автоматическое решение Proof-of-Work (PoW) капчи QRATOR и имитация браузера Chrome через `curl_cffi`.
* 🚫 **Система стоп-слов**: Исключает объявления со словами «на запчасти», «не работает», «копия» и др. Можно добавлять прямо из уведомления в 1 клик!
* 📋 **Быстрый шаблон продавцу**: Кнопка «📋 Скопировать сообщение» под каждым новым объявлением для мгновенной отправки сообщения на Авито.
* 🗂 **Удобное управление поисками**: Список всех отслеживаний, возможность поставить на паузу, возобновить или удалить.
* 📦 **Защита от спама**: При первичном добавлении ссылки старые объявления запоминаются в базу данных и не засоряют чат.
* 🐳 **Готов к работе 24/7 на сервере**: В комплекте `Dockerfile`, `docker-compose.yml` и `systemd` сервис.

## 🚀 Быстрый запуск локально (Windows / Linux / Mac)

### 1. Клонирование и переход в папку
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd "avito parser tg bot"
```

### 2. Создание виртуального окружения
```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка `.env`
Создайте файл `.env` (скопировав `.env.example`):
```bash
cp .env.example .env
```
Откройте `.env` и вставьте ваш токен бота от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
CHECK_INTERVAL=60
MAX_SEARCHES_PER_USER=10
PROXY_URL=
```

### 5. Запуск бота
```bash
python bot.py
```

## 🌐 Развертывание на сервере (VPS) 24/7

### Вариант 1: Через Docker Compose (Рекомендуется)

1. Установите Docker и Docker Compose на сервере:
   ```bash
   apt update && apt install -y docker.io docker-compose
   ```
2. Скопируйте проект на сервер или склонируйте через `git`.
3. Создайте `.env` и укажите `BOT_TOKEN`.
4. Запустите в фоновом режиме:
   ```bash
   docker-compose up -d --build
   ```
5. Просмотр логов:
   ```bash
   docker-compose logs -f
   ```

### Вариант 2: Через systemd (Ubuntu / Debian)

1. Поместите проект в `/opt/avito_parser_bot`.
2. Создайте venv и установите зависимости:
   ```bash
   python3 -m venv /opt/avito_parser_bot/venv
   /opt/avito_parser_bot/venv/bin/pip install -r /opt/avito_parser_bot/requirements.txt
   ```
3. Скопируйте файл сервиса:
   ```bash
   cp /opt/avito_parser_bot/avito-bot.service /etc/systemd/system/
   systemctl daemon-reload
   systemctl enable --now avito-bot
   ```
4. Проверить статус:
   ```bash
   systemctl status avito-bot
   ```

## ⚙️ Структура проекта

```
├── bot.py                # Точка входа, запуск бота и диспетчера
├── config.py             # Загрузка конфигурации из .env
├── database.py           # Асинхронная работа с SQLite (поиски, история, стоп-слова)
├── parser.py             # Парсер Авито с автообходом PoW-защиты
├── scheduler.py          # Фоновый процесс мониторинга поисков 24/7
├── handlers/             # Обработчики команд Telegram
│   ├── common.py         # /start, помощь, шаблон по умолчанию
│   └── searches.py       # Добавление поиска, мои поиски, стоп-слова
├── Dockerfile            # Сборка Docker контейнера
├── docker-compose.yml    # Запуск бота в Docker 24/7
├── avito-bot.service     # Конфигурация для Linux systemd
├── requirements.txt      # Список зависимостей
└── .gitignore            # Игнорируемые файлы (база, логи, venv)
```
